# CS3300GroupProject (HorizonHub)

## Class Information
- **Class Name:** CS 3300
- **University:** University of Colorado, Colorado Springs
- **Semester:** Fall 2024

## Description
This repository contains the group project for CS 3300 at the University of Colorado Colorado Springs, developed during the Fall 2024 semester. With all code implemented in Python and TypeScript.

This README servers as an out-of-character brief for the project.

## Documentation
Documentation can be found inside further folders. Inside `horizonhub-hotel-manager`, `horizonhub-hotel-manager/frontend`, and `horizonhub-hotel-manager/backend` you will find their respective READMEs.

Documentation on usage will be mostly in `horizonhub-hotel-manager` with some in `horizonhub-hotel-manager/frontend` and `horizonhub-hotel-manager/backend`, but(`horizonhub-hotel-manager/frontend/` and `horizonhub-hotel-manager/backend/`) are mainly for developers.

These will be toned and worded as if HorizonHub was an actual product.

## User Guides
User Guides can be found inside `UserGuides/`.

We have some both for our end user (The Businesses who use HorizonHub referred to as B2B Customers), and their end users as well (The Customers of the Businesses who use HorizonHub referred to as B2C Customers).
